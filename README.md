# Study Fuel - Tiffin Service & Smart Manager

Next.js + TypeScript web application for tiffin delivery operations, daily attendance, customer portals, kitchen prep calculation, and automated WhatsApp communication.

## Framework & Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + PostCSS
- **Icons:** Lucide React
- **Animations:** Motion
- **PDF Generation:** jsPDF + AutoTable

## Getting Started

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```
